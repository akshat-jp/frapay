#  Getting Started

## Clone the Repository

```bash
git clone https://github.com/yourusername/frapay.git
cd frapay
```

---

## Install Dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd backend
npm install
```

---

## Setup Environment Variables

Create a `.env` file inside backend:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

---

## Run the Project

### Frontend

```bash
npm run dev
```

### Backend

```bash
node index.js
```

#  How It Works

1. Visit the live site: [Frapay](https://frapay-frontend.vercel.app/) 
2. Create an account
3. Receive random credits instantly
4. Search users
5. Transfer money securely
